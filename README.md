1. Crea una función `greet()` que imprima **“Hello world”** por consola.

2. Crea una función `greet(name)` que imprima **“Hello <nombre>”** por consola, y llámala varias veces con distintos nombres.

3. Crea una función `pow(a, b)` que devuelva el resultado de `a^b`.

4. Crea una función `celsius_to_fahrenheit(temperature)` que transforme Celsius en Fahrenheit y devuelva el resultado.

5. Crea una función `area_circle(radius)` que devuelva el área de un círculo.

6. Crea una función `avg(a, b, c)` que devuelva la media de tres números `a`, `b` y `c`.

7. Crea una función `concat(a, b, c)` que devuelva una única cadena de texto, concatenando las cadenas `a`, `b` y `c`.

8. Crea una función `full_name(name, surname1, surname2)` que devuelva el nombre completo de una persona.

9. Crea una función `current_age(birth_year)` que devuelva la edad actual de una persona (sin tener en cuenta el día).

10. Crea una función `introduction(name, surname1, surname2, birth_year)` que utilice las 2 funciones anteriores e imprima por pantalla:

    **“Hello, I’m <nombre completo> and I’m <edad> years old”**

11. Crea una función `welcome()` que imprima **“Welcome to this Python lesson”** por consola.

12. Crea una función `welcome(name)` que imprima **“Hello, <nombre>, welcome to this Python lesson”** por consola.

13. Crea una función `double(number)` que devuelva el doble de un número.

14. Crea una función `price_with_tax(price)` que devuelva el precio de un producto sumándole el IVA (21%).

15. Crea una función `price_with_tax(price, tax)` que devuelva el precio de un producto sumándole el impuesto dado como parámetro.

16. Crea una función `volume_cube(side)` que devuelva el volumen de un cubo.

    > El volumen de un cubo es `lado³`.

17. Crea una función `time_to_seconds(hours, minutes, seconds)` que devuelva el número total de segundos, dado un número de horas, minutos y segundos.

18. Crea una función `pretty_text(text)` que devuelva una cadena con el formato **“=== <texto> ===”**.

    > Por ejemplo: **“=== My cool text ===”**

19. Crea una función `format_name(name, surnames)` que devuelva una cadena de texto con el formato **“<Apellidos>, <Nombre>”**.

    > Por ejemplo: **“Pérez Álvarez, Pepito”**

20. Crea una función `passed(grade1, grade2, grade3)` que calcule la media de tres notas y devuelva `True` o `False`, según si la media es mayor o igual que 5.

21. Crea una función `student_passed(name, surnames, grade1, grade2, grade3)` que imprima por consola:

    **“<Apellidos>, <Nombre> has passed the subject: <True/False>”**

    > Por ejemplo: **“Pérez Álvarez, Pepito has passed the subject: True”**
